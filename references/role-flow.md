# 主 Agent 与角色 subagent 的演绎接入契约

此处是宿主接入规范，不是已实现的自动调度系统。仍只有三层；Rule 是运行约束，当前上下文由模型维护，永久文件保存轨迹与历程。

## 分工与信息边界

1. 主 Agent 依据世界设定、已确立历史与当前剧情整理宏观客观切面和各人的个人客观切面。不同角色的私人事件不必写入第一层。
2. 主 Agent 在管理侧结合某角色第二层、此前第三层及有依据的当前心境，形成下一段使用的个人主观输入。客观真相经过角色已知信息、误解与心境过滤，可以形成偏离客观的理解；不得反向改写客观历史。
3. 分别给角色 subagent 适用 Rule、该角色第三层输入与获准当前场景。subagent 根据这些输入判断，输出自己的行动和回应。主 Agent 不用第三层输入预定其下一步决定。
4. 主 Agent 将回应放回当前演绎上下文，核查行动结果与允许他人感知的部分。私人心理活动不自动向其他角色传播；subagent 的意图或猜测不自动成为世界中已发生的事实。
5. 玩家要求归档时，按实际演绎结果整理三层增量、审核后保存。演绎中的临时第三层输入不自动提交，也不构成另一套永久权威。

每名角色输入只包含仍可用、与当下判断有关的自身历程及认知，不堆入全部旧记录。筛选不能只留下当前结论，抹掉解释当前选择所需的转折；预算不足时保留关键未知边界与未解决事件，明确取舍。没有固定默认字数或新检索引擎。

执行 consolidation.md 的读取规则：按当前场景选择相关历程，读取省略不等于遗忘，不因此改写永久认知。role 工具的全量 available 输出须由管理侧再次选择，不能当成已经按场景限长。

Rule 应明确适用范围：共同的玩家行动权与生成约束可以传给角色；管理侧的隐藏设定、未知客观原因和带秘密的指令不能传给角色。角色主观认知不能覆盖玩家控制权或其他规则。

宿主须实际限制每个 subagent 的工具、文件和会话历史。仅分开提示词或要求“假装不知道”不是硬隔离。不要从包含客观秘密的完整会话 fork 角色并声称干净；需要未接触这些秘密的角色上下文。

## 双角色用例：失约解释之前

输入来自 examples/initial.txt 与 batch-1.txt。主 Agent 已知 Ren 因阑尾炎住院；Saki 只知道失约。batch-1 明确给出 Saki 心境缓和、开始重新理解，不允许主 Agent 自行补出原谅。

管理侧核查：第一层无变化；Saki 第二层为等待失约、当前询问原因；Ren 第二层含住院及走近。两者不合并成共同已知信息。

**Saki subagent 的输入**

```text
适用 Rule：只决定自己的言行，不替玩家或他人决定；按场景分段。
第三层：记得那次失约。此前认定这意味着 Ren 不在乎自己；现在心境缓和，认为也许有别的困难，但仍不知道原因，也未决定原谅。
当前场景：桥边。你刚问 Ren 为什么当年没来，他尚未回答。
任务：据此判断接下来的回应；不要把猜测当事实。
```

**Ren subagent 的输入**

```text
适用 Rule：只决定自己的言行，不替玩家或他人决定；按场景分段。
第三层：记得自己当时因阑尾炎住院而未能赴约。
当前场景：桥边。Saki 问你当年为什么没来；她没有表达自己的私人想法。
任务：据此判断自己的回应。
```

Ren 包不含 Saki 的“不在乎”或心境变化；Saki 包不含住院真相，也不含“你不知道 Ren 住院”的泄密标签。两包只是主 Agent 按 Skill 准备的输入样例，不是实际隔离 subagent 的实验结果。

若 Ren 后续告诉 Saki 自己住院，Saki 才可根据获准对话形成“他给出了住院解释、尚未核实”的第三层。具体判断由她的 subagent 完成；沉默不自动等于原谅。正式归档记录已发生的说法与认知变化，而不是把主 Agent 的候选心理解释偷偷保存。
