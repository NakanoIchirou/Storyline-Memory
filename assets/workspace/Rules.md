# 作者规则与运行约束

此文件不属于三层 Storyline。这里的文字是配置；写死在程序中的行为才是硬编码。

- 只有玩家明确要求时归档；草案经审核后提交，三层一起回滚。
- 世界管理侧核查三层；角色只能收到自己当前获准的第三层与允许感知的信息。
- 主 Agent 结合各角色第二层、此前第三层与当前心境，形成下一段的第三层输入；角色 subagent 根据适用规则、自己的第三层及获准场景进行判断。不得共享客观档案或其他角色私密认知。
- Rule 按管理侧与角色侧注明适用范围。含隐藏设定的规则只给管理侧，不随公共规则泄露。第三层承接个人历程，不预先强制角色的下一步行动。
- 演绎输入在当前上下文中发展，正式轨迹只在玩家主动归档、审核后保存。
- 玩家决定角色接入、淡出和重大设定修订。
- 叙事语气、分段方式和其他作者约束由玩家填写。

具体地理、制度、身份、关系和心理状态写入对应 Storyline。只有作者明确指定的不可变约束才放在这里，不自动把初始事实变成永久规则。
